# Reporting Release Evidence

## Cycle And Version

Record reporting period, cut off, source receipt, source checksum, contract version, report version, readiness outcome and approving role.

## Control Results

| Control ID | Result | Finding | Owner | Evidence reference |
| --- | --- | --- | --- | --- |
|  | Pass / Fail / Caveat |  |  |  |

## Accepted Caveats

For each caveat, record affected KPI or decision, owner, rationale, expiry and corrective action. A missing field fails the release evidence check.

## Publication And Review

Record the approved report version, publication timestamp, access test result, decisions, actions, owners, due dates and success evidence.

## Boundary

State which evidence came from automated execution, manual review, simulation or assumption. Do not present an example as runtime proof.
